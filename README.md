# Telegram-бот записи

Бот для записи клиентов на услуги (салоны, барбершопы, СТО, репетиторы и т.п.).
Написан на Python и aiogram 3.

## Что умеет
- `/start` — главное меню
- **Записаться** — пошагово: услуга → день → время → подтверждение
- **Прайс** — список услуг и цен
- **Мои записи** — только предстоящие записи + отмена своей записи
- **Админка** (только для админа):
  - разделы «Предстоящие / Прошедшие / Завершённые»;
  - карточка каждой записи с данными клиента;
  - «✅ Завершить» — запись помечается выполненной;
  - «❌ Отменить» — запись удаляется, клиент получает уведомление;
  - завершённые записи удаляются автоматически через сутки
- Уведомление админу о новой записи и об отмене клиентом
- Напоминание клиенту за день до записи
- Прошедшие часы и занятые слоты не показываются при записи

## Структура
```
bot.py          — точка входа, подключает модули
config.py       — настройки: услуги, цены, график работы, админ
database.py     — база данных SQLite (файл data.db создаётся сам)
keyboards.py    — все клавиатуры
reminders.py    — фоновые напоминания клиентам
handlers/
  common.py     — /start, прайс, мои записи, отмена записи
  booking.py    — процесс записи (FSM)
  admin.py      — админка: разделы, завершение, отмена
```

## Установка
```bash
pip install -r requirements.txt
```

## Настройка
Открой файл `.env` и заполни:
```
BOT_TOKEN=токен_от_BotFather
PROXY_URL=            # если Telegram недоступен напрямую
ADMIN_ID=             # твой ID (узнать у @userinfobot) — для админки
```

## Настройка услуг
Услуги и цены меняются в файле `config.py` в словаре `SERVICES`.
График работы — там же: `WORK_START`, `WORK_END`, `DAYS_AHEAD`.

## Админка
Кнопка «Админка» появляется только у пользователя, чей ID указан в `.env`
(`ADMIN_ID`). У остальных её нет.

Внутри — три раздела со счётчиками:
- **Предстоящие** — активные записи на сегодня и позже;
- **Прошедшие** — активные записи, дата которых уже прошла;
- **Завершённые** — записи, помеченные кнопкой «✅ Завершить».

В карточке записи доступны:
- **✅ Завершить** — статус меняется на «Завершена»;
- **❌ Отменить** — запись удаляется, слот освобождается, клиенту
  приходит уведомление в Telegram.

Завершённые записи хранятся сутки после отметки, затем удаляются
автоматически (фоновая проверка каждые 30 минут). Срок меняется
параметром `cleanup_done_bookings(days=1)` в `database.py`.

## Запуск
```bash
python bot.py
```

## Если Telegram недоступен (блокировка)
Если при запуске ошибка вида `WinError 10060` / таймаут — значит `api.telegram.org` блокируется провайдером. Варианты:
1. Включить VPN на весь компьютер.
2. Указать прокси в `.env`:
   ```
   PROXY_URL=socks5://user:pass@host:port
   ```
3. Запустить бота на сервере (VPS) за пределами РФ.
