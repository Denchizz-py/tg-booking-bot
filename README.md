# Telegram-бот записи

Бот для записи клиентов на услуги (салоны, барбершопы, СТО, репетиторы и т.п.).
Написан на Python и aiogram 3.

## Что умеет
- `/start` — главное меню
- **Записаться** — пошагово: услуга → день → время → подтверждение
- **Прайс** — список услуг и цен
- **Мои записи** — список записей + отмена своей записи
- **Админка** (только для админа) — все записи + удаление
- Уведомление админу о новой записи и об отмене
- Напоминание клиенту за день до записи
- Прошедшие часы и занятые слоты не показываются при записи

## Структура
```
bot.py          — точка входа, подключает модули
config.py       — настройки: услуги, цены, график работы, админ
database.py     — база данных SQLite (файл data.db создаётся сам)
keyboards.py    — все клавиатуры
reminders.py    — фоновые напоминания клиентам
handlers/
  common.py     — /start, прайс, мои записи, отмена записи
  booking.py    — процесс записи (FSM)
  admin.py      — админка
```

## Установка
```bash
pip install -r requirements.txt
```

## Настройка
Открой файл `.env` и заполни:
```
BOT_TOKEN=токен_от_BotFather
PROXY_URL=            # если Telegram недоступен напрямую
ADMIN_ID=             # твой ID (узнать у @userinfobot) — для админки
```

## Настройка услуг
Услуги и цены меняются в файле `config.py` в словаре `SERVICES`.
График работы — там же: `WORK_START`, `WORK_END`, `DAYS_AHEAD`.

## Запуск
```bash
python bot.py
```

## Если Telegram недоступен (блокировка)
Если при запуске ошибка вида `WinError 10060` / таймаут — значит `api.telegram.org` блокируется провайдером. Варианты:
1. Включить VPN на весь компьютер.
2. Указать прокси в `.env`:
   ```
   PROXY_URL=socks5://user:pass@host:port
   ```
3. Запустить бота на сервере (VPS) за пределами РФ.
